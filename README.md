One impossible fish: a glowing golden koi, far too big for the room it swims through, bursting out of a tiny porcelain teacup while the water spirals up after it and a paper boat rides the crest. Drawn entirely in code — the picture is painted by an HTML canvas page (`gen_koi.html`) and rendered to a 1024×1024 image — for make.fun's "Make the AI judge excited" bounty, $250 in USDC.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` byte-for-byte to the output directory — nothing else, no network, fully deterministic.
